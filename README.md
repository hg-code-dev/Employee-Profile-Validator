# Employee Profile Validator
A Python script developed as part of the freeCodeCamp Python certificate course. 
This project demonstrates fundamental string manipulation and validation techniques in Python. 
The **Employee Profile Validator** processes and cleans mock employee records (names, emails, phone numbers, and IDs), demonstrating real-world data standardisation and validation techniques in Python.

## 📚 What I Covered & Learned
* **Index & Substrings:** Used `.find()` to locate specific characters like `@`.
* **String Slicing:** Extracted substrings (e.g., separating a username from an email).
* **Membership Testing:** Checked for characters using the `in` operator.
* **Casing & Whitespace:** Cleaned untidy strings using `.strip()`, `.lower()`, `.upper()`, and `.title()`.
* **Replacing & Formatting:** Swapped out characters using `.replace()` and formatted outputs with f-strings.
* **Splitting & Joining:** Broke addresses apart with `.split()` and reconnected them with `.join()`.
* **Validation & Counting:** Verified patterns with `.startswith()` / `.endswith()` and tallied characters with `.count()`.
